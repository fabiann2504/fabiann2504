### 💳 Cloud Payment — Whitelabel QRIS Payment Gateway

Gateway pembayaran **QRIS dinamis** yang saya rancang & bangun sendiri, sudah berjalan di domain publik.

- QRIS dinamis lewat **Midtrans Core API** (`POST /v2/charge`) — QR unik dengan nominal terkunci
- **Webhook** tunggal + verifikasi signature SHA-512, **idempotent** (mustahil dobel kredit)
- Saldo **hanya** dikredit setelah status diverifikasi ulang ke Midtrans → `expire` / `cancel` / `deny` / `fraud` tidak pernah menambah saldo
- API Key merchant (`X-API-Key`), mode **sandbox** & **production** terpisah, ledger atomik (`FOR UPDATE`)
- Top-up, withdraw (min Rp 30.000 · T+3), panel admin, OTP email, Cloudflare Turnstile, SEO penuh
